# 照片位与命名规范（给监理现场人员的拍照建议）

## 一、拍照时就把关键信息带上（三选一，越多越稳）

| 方式 | 做法 | 识别可靠性 |
|---|---|---|
| 水印相机 | 用水印相机（如今日水印、马克水印等）在“备注/自定义字段”里写设备序列号或编号，同时保留时间、地点 | 高（本地 OCR） |
| 文件名 | 导出后批量改名：`<序列号>_<检查项>.jpg`，如 `2102311QFG10K9000123_铭牌.jpg` | 最高 |
| 文件夹 | 按设备或问题建文件夹：`现场照片/2102311QFG10K9000123/xxx.jpg` | 最高 |

建议：**铭牌照必拍**，铭牌上的序列号也能被 OCR 读出。水印字号不要太小，背景要有对比。

## 二、文件名示例

| 文件名 | 能匹配到 |
|---|---|
| `服务器_20261120.jpg` | 只能按日期和“服务器”关键词匹配，分不到具体设备（需水印补充序列号） |
| `SN-A0003_铭牌.jpg` | `{{照片:SN-A0003}}`、`{{照片:SN-A0003&铭牌}}` |
| `20261126_3号机柜_加电.jpg` | `{{照片:日期=2026-11-26&3号机柜}}`、`{{照片:加电}}` |
| `问题1_布线标签缺失.jpg` | `{{照片:问题1}}`（用于通知单问题条目） |

## 三、照片位怎么写

- **一台设备一个照片位**，关键字用合同清单或到货清单里的序列号，与表格同一行：
  `| 5 | 1 | 机架式服务器 | … | A2215279K04 | 合格 | 正常 | | {{照片:A2215279K04}} |`
- 同一设备要区分多张照片时用“且”：`{{照片:A2215279K04&铭牌}}`、`{{照片:A2215279K04&加电}}`。
- 关键字不要太宽。比如“机房”可能出现在每张照片的地点水印里，会把所有照片都匹配进来。报告第四节会提示“照片过多”。
- 序列号太短（少于 5 位）时只做精确匹配，最好改用完整序列号或设备编号。

## 四、常见问题

| 现象 | 原因与处理 |
|---|---|
| 某设备“缺照片” | 没拍、水印被遮挡、序列号拍错。看报告第五节“未匹配照片”里识别到的文字，手工补一行到匹配表 |
| 低置信度匹配 | OCR 把个别字符认错。核对后把“采用”改为“是” |
| 一图多位 | 一张照片里拍了多台设备的序列号。确认后保留，或把多余的行改为“否” |
| 照片横竖颠倒 | 渲染时按 EXIF 方向自动纠正；OCR 也会自动尝试旋转 |
| HEIC 照片（iPhone） | 需要 `pip install pillow-heif`，或在手机设置里改为“兼容性最佳”（JPG） |
| Word 文件过大 | 照片已压缩到长边 1600 px；仍过大时用 `--max-per-slot 2` 限制每台设备的张数 |
