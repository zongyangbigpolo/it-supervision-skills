# 验收条件与资料清单

按验收类型挑选适用条目。“必需”以合同约定为准，合同未约定的按下表建议执行，并在验收意见中注明“合同未约定，按监理建议执行”。

## 一、通用资料（各阶段）

| 编码 | 资料 | 提供方 | 必需 |
|---|---|---|---|
| G-01 | 验收申请（报验单） | 承建单位 | ✔ |
| G-02 | 阶段工作总结/自检报告 | 承建单位 | ✔ |
| G-03 | 本阶段交付物清单（与合同对照） | 承建单位 | ✔ |
| G-04 | 前期监理通知单及回复单、问题闭环台账 | 监理单位 | ✔ |
| G-05 | 会议纪要、变更文件 | 各方 | 有则提供 |

## 二、设计阶段

| 编码 | 资料 | 必需 |
|---|---|---|
| D-01 | 需求规格说明书（含需求跟踪矩阵） | ✔ |
| D-02 | 概要设计说明书、详细设计说明书 | ✔ |
| D-03 | 数据库设计说明书、接口设计说明书 | ✔ |
| D-04 | 网络拓扑与 IP 规划、设备部署图 | 硬件项目 ✔ |
| D-05 | 等保安全设计方案 | 有等保要求 ✔ |
| D-06 | 设计评审意见及修改确认 | ✔ |

## 三、到货与安装阶段

| 编码 | 资料 | 必需 |
|---|---|---|
| H-01 | 全部批次《硬件设备到货验收单》 | ✔ |
| H-02 | 设备序列号台账（与到货单一致） | ✔ |
| H-03 | 原厂授权、合格证、保修卡/原厂服务证明 | ✔ |
| H-04 | 安装调试记录、配置文档 | ✔ |
| H-05 | 综合布线测试报告 | 含布线 ✔ |
| H-06 | 机房环境检测报告（接地、UPS、空调） | 含机房 ✔ |

## 四、软件部署/联调阶段

| 编码 | 资料 | 必需 |
|---|---|---|
| S-01 | 系统测试方案与测试报告（功能/性能/兼容性） | ✔ |
| S-02 | 集成/接口联调记录 | ✔ |
| S-03 | 缺陷清单及处理记录 | ✔ |
| S-04 | 安全测试报告（漏扫/渗透/代码审计） | ✔ |
| S-05 | 部署手册、用户手册、运维手册 | ✔ |
| S-06 | 培训记录（签到表、培训材料） | ✔ |
| S-07 | 第三方软件测评报告 | 合同要求时 ✔ |

## 五、初验

前置条件：

- [ ] 合同约定的全部建设内容已实施完成
- [ ] 上述二至四类资料齐全
- [ ] 前期监理通知单全部关闭，或未关闭项已列入遗留问题清单且均为 B/C 类
- [ ] 等保测评已完成（合同约定初验前完成时）
- [ ] 建设单位用户代表已参与功能确认

## 六、试运行

| 编码 | 资料 | 必需 |
|---|---|---|
| T-01 | 试运行方案（周期、范围、指标） | ✔ |
| T-02 | 试运行日志/运行报告（可用性、性能、故障统计） | ✔ |
| T-03 | 试运行期问题清单及处理记录 | ✔ |
| T-04 | 用户使用报告/满意度确认 | 建议 |

## 七、终验

前置条件：

- [ ] 初验通过且初验遗留问题全部关闭
- [ ] 试运行期满且运行稳定
- [ ] 等保测评通过（结论满足合同要求），备案证明已取得
- [ ] 源代码、文档、账号口令、授权许可等按合同移交
- [ ] 竣工资料（含全部监理资料）已整理并移交建设单位
- [ ] 质保/运维服务承诺书已提交
