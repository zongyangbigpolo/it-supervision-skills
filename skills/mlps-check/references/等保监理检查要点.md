# 等保监理检查要点

> 本文件为监理视角的**检查提示**，以监理可核查的证据为导向，非 GB/T 22239-2019 原文。具体控制点与要求项以标准原文和测评机构的测评指导书为准。条款编号不要凭记忆引用。

## 一、流程性要求（监理重点核查节点与时限）

| 事项 | 监理核查要点 |
|---|---|
| 定级 | 定级对象边界清晰（承载的业务、网络范围、资产）；依据 GB/T 22240-2020 确定业务信息与系统服务两方面的安全保护等级；定级报告经专家评审 |
| 备案 | 第二级及以上须向公安机关备案并取得备案证明；办理时限按当地公安机关网安部门现行要求执行，监理只核查是否在时限内办理 |
| 建设整改 | 有差距分析与整改方案；整改项与差距项一一对应 |
| 测评 | 第三级系统一般每年至少开展一次等级测评，第四级更频繁（以现行规定为准）；新建系统应在上线前或合同约定时点完成测评 |
| 测评机构 | 核查测评机构具备开展等级测评的资质/认证（核查证书或官方推荐目录，记录证书编号与有效期）；测评人员持证 |
| 测评结论 | 测评报告给出结论等级（优/良/中/差）与综合得分；存在高风险项通常无法达到“中”及以上。具体判定规则以测评报告模板现行版本为准 |
| 密评（如需） | 依据 GB/T 39786-2021 开展商用密码应用安全性评估，与等保同步规划 |

## 二、安全技术要求（以第三级为例，二级适当裁剪，四级加强）

| 层面 | 监理核查要点（看什么证据） |
|---|---|
| 安全物理环境 | 机房位置与防护、门禁与出入记录、视频监控、防雷接地、消防、温湿度控制、UPS/双路供电、电磁防护；云上系统由云服务商提供合规证明 |
| 安全通信网络 | 网络架构分区分域、核心设备与链路冗余、带宽满足业务高峰、重要网段之间有访问控制、远程管理与数据传输使用加密（如 HTTPS/SSH/VPN）、通信设备的可信验证（如适用） |
| 安全区域边界 | 边界防火墙策略最小化、无“any to any”、非授权接入与外联检测、入侵防范、恶意代码/垃圾邮件防范、边界安全审计、无线接入受控 |
| 安全计算环境 | 身份鉴别（口令复杂度、定期更换、登录失败处理、双因素/多因素认证——三级对管理员要求两种及以上鉴别方式）、访问控制与默认账户清理、安全审计开启且日志留存不少于 6 个月、入侵防范（关闭多余端口与服务、漏洞修补）、恶意代码防范、数据完整性与保密性（重要数据传输/存储加密）、数据备份恢复（本地备份 + 异地备份）、剩余信息保护、个人信息保护 |
| 安全管理中心 | 系统管理、审计管理、安全管理三权分立；集中管控（统一运维审计/堡垒机、集中日志、集中监控、补丁与病毒库集中管理）；管理网络独立或带外 |

## 三、安全管理要求

| 层面 | 监理核查要点 |
|---|---|
| 安全管理制度 | 总体方针策略、各类管理制度、操作规程、记录表单四层体系；制度经审批发布并定期修订 |
| 安全管理机构 | 安全领导小组/职能部门、岗位设置（安全主管、系统/审计/安全管理员）、授权审批、沟通合作、定期安全检查 |
| 安全管理人员 | 录用审查、离岗手续、安全意识教育与技能培训、外部人员访问管理 |
| 安全建设管理 | 定级备案、安全方案设计、产品采购（网络安全专用产品具备销售许可/认证）、自行/外包软件开发安全、工程实施管理、测试验收、系统交付、等级测评、服务供应商管理 |
| 安全运维管理 | 环境与资产管理、介质管理、设备维护、漏洞与风险管理、网络与系统安全管理、恶意代码防范、配置管理、密码管理、变更管理、备份与恢复、安全事件处置、应急预案及演练、外包运维管理 |

## 四、测评报告审核要点

1. 被测对象名称、等级与备案证明一致；
2. 测评范围（资产清单）覆盖本项目建设与上线的全部服务器、网络与安全设备、数据库、中间件、应用；
3. 记录：结论等级、综合得分、高/中/低风险项数量；
4. 高风险项：逐项核对是否已整改并复测；
5. 中风险项：有整改计划或风险接受说明（须建设单位书面确认）；
6. 测评机构签章、报告编号、报告日期齐全。
