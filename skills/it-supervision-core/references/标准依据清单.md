# 标准依据清单

> 引用前请提醒用户核对标准的**现行有效版本**（可在“全国标准信息公共服务平台” std.samr.gov.cn 查询）。本清单仅列出常用标准名称，不复述标准正文；不要编造具体条款号与条文内容，需要条款时请用户提供原文或写“相关条款”。
