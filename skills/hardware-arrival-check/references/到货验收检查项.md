# 到货验收检查项

结果：合格 / 不合格 / 不适用 / 未核查。

## 一、批次与单据

| 编码 | 检查项 | 要点 |
|---|---|---|
| A-01 | 到货报验 | 承建单位提前报验（合同或监理规划约定的提前天数） |
| A-02 | 装箱单/送货单 | 与实物一致，供货单位签章 |
| A-03 | 物流与包装 | 外包装完好、无破损、无受潮、封箱胶带/防伪封条完整、无二次开封痕迹 |

## 二、品牌型号与配置

| 编码 | 检查项 | 要点 |
|---|---|---|
| B-01 | 品牌、型号 | 与合同/投标清单一致 |
| B-02 | 主要配置 | CPU、内存、硬盘、网卡、电源、端口数、光模块、授权数等不低于合同；服务器可开机进 BIOS/BMC 核对 |
| B-03 | 软件授权 | 许可证书/授权码数量、版本、授权期限、授权对象（建设单位名称） |
| B-04 | 型号替换 | 有替换时核查建设单位书面同意文件 |

## 三、数量与序列号

| 编码 | 检查项 | 要点 |
|---|---|---|
| C-01 | 数量 | 本批实到与送货单一致；累计到货不超合同 |
| C-02 | 序列号 | 机身铭牌、包装标签、到货清单三者一致；无重复 |
| C-03 | 保修查询 | 原厂官网/400 查询保修状态、起始日期合理（非旧机） |

## 四、随机资料与证明

| 编码 | 检查项 | 要点 |
|---|---|---|
| D-01 | 产品合格证 | 每台/每批 |
| D-02 | 保修卡/原厂服务承诺函 | 服务年限与合同一致 |
| D-03 | 原厂授权函（项目授权） | 合同/招标要求时 |
| D-04 | 3C 认证标志 | 列入强制性产品认证目录的设备 |
| D-05 | 报关单/原产地证明 | 进口设备且合同要求时 |
| D-06 | 用户手册、驱动、随机附件（导轨、电源线、跳线、光模块） | 齐全 |
| D-07 | 网络安全专用产品资质 | 防火墙、IDS/IPS、WAF 等安全产品的销售许可/认证证书 |

## 五、外观与加电

| 编码 | 检查项 | 要点 |
|---|---|---|
| E-01 | 外观 | 无划痕、变形、锈蚀，标签完整 |
| E-02 | 加电自检 | 指示灯正常、无告警；BMC/管理口可登录；硬件健康状态正常 |
| E-03 | 固件版本 | 记录版本，必要时与合同/方案要求对照 |

## 六、合规与信创（适用时）

| 编码 | 检查项 | 要点 |
|---|---|---|
| F-01 | 信创产品 | CPU/操作系统/数据库型号在合同约定范围内 |
| F-02 | 节能/环保 | 政府采购节能产品要求（如适用） |
