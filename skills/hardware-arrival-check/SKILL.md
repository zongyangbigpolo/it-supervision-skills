# 硬件设备到货验收

## 前置

先执行 `it-supervision-core` 第 0 步；`CORE_DIR=<本目录>/../it-supervision-core`；`SKILL_DIR=<本目录>`。

## 需要的输入

| 输入 | 说明 | 格式 |
|---|---|---|
| 合同/投标设备清单 | 合同附件中的设备清单（名称、品牌、型号、主要配置、数量、单价） | CSV / XLSX / 表格粘贴 |
| 到货清单 | 供货单位装箱单或现场清点结果，**每台设备一行**，含序列号 | CSV / XLSX / 照片转录 |
| 批次信息 | 到货日期、批次号、到货地点、物流单号、供货单位 | 文本 |
| 现场检查记录 | 外观、包装、随机附件、合格证、加电情况 | 文本/照片说明 |

模板：[templates/合同设备清单.csv](templates/合同设备清单.csv)、[templates/到货清单.csv](templates/到货清单.csv)（UTF-8 带 BOM，Excel 直接打开不乱码）。用户给的是照片或 PDF 时，先转录为上述 CSV 并请用户核对转录结果。

## 工作流

1. **比对**（自动）：
   ```bash
   python3 "${SKILL_DIR}/scripts/compare_delivery.py" 合同设备清单.csv 到货清单.csv \
     -o 监理资料/06-到货验收/比对结果_<批次>.md
   ```
   输出：按“合同项号”汇总的应到/本批实到/累计实到/差异，型号或品牌不一致项，重复序列号，缺序列号项，合同外设备。支持 `.xlsx`（需 openpyxl）。累计到货可传入多个到货清单：`--previous 第1批.csv 第2批.csv`。
2. **现场检查**：按 [references/到货验收检查项.md](references/到货验收检查项.md) 逐项记录；无法现场核实的项填“未核查”，不得默认“合格”。
3. **分配编号**：`next_doc_no.py --type DH --title "第N批到货验收"`。
4. **起草验收单**：按 [templates/硬件设备到货验收单.md](templates/硬件设备到货验收单.md)，把比对结果表与检查项结果写入；设备明细较多时，明细作为附件（横向页面 `<!-- landscape -->`）。
5. **结论**：
   - 合格：数量、型号、配置一致，证明文件齐全，外观与加电正常；
   - 有条件合格：存在不影响使用的缺项（如合格证后补），限期补齐；
   - 不合格：型号/配置低于合同、数量严重短缺、疑似非原厂/翻新、加电故障——**拒收或退换**，并建议签发监理通知单。
6. **投资控制提示**：在验收单中写明“本批到货金额（按合同单价计算）”，作为到货款审核依据；金额用 `common.py` 的大写转换。
7. 校验 & 渲染；三方 + 供货单位签章。

## 注意

- 型号替换（停产、升级）必须有建设单位书面同意的变更文件，否则按“不一致”处理。
- 进口设备核查报关单/原产地证明（合同要求时）；信创项目核查产品是否在合同约定的目录/型号范围内。
- 序列号应以设备机身铭牌为准，与包装箱标签、原厂官网保修查询结果三者核对（官网查询由用户执行并截图，你不要声称已查询）。
